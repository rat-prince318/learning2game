# 灰冠战役美术

本目录的插画与首领两阶段立绘由项目使用 ImageGen 生成，作为本地静态资源随游戏分发。探索场景的社区图集和许可见[地图美术清单](../region-art/ASSETS.md)。

| 资源 | 生成与加工 | 游戏用途 |
| --- | --- | --- |
| ferry.webp | 夜色渡口、红披风斥候、逆流军船与桅灯，横幅构图 | 灵船和盐港事件 |
| forge.webp | 老战士与赤红熔炉，铜铁、火花和高反差像素轮廓 | 炉场与风帆突袭 |
| mirror.webp | 雪色关隘、镜面石壁和前线人物 | 复写馆、镜隘与钟桥事件 |
| orrery.webp | 黎明星门、带盾先锋和弩手举旗，破冠龙将伏在熄炉旁 | 决战及战后命令 |
| [铁冠形态](../../battle/art/ash-crown-armored.png)、[开炉形态](../../battle/art/ash-crown-enraged.png) | 同一头灰冠龙将的左向战场立绘，透明背景。分别裁切、缩放和对齐足点 | 战场根据服务器返回的首领阶段切换形态 |
| [渡口灵船](../region-art/ghost-ship.webp) | 带红帆与缆索的透明俯视船体，裁切后保留水线 | 可走到船首调查 |

战役采用经典日式 RPG 中集结队伍、向敌方首领进军的结构。八座驿站、灰冠、赤翎、选择及对白为项目创作。[《勇者斗恶龙 III》发行方介绍](https://www.square-enix-games.com/en_GB/news/dragon-quest-iii-hd-2d-remake)
