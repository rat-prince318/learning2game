# 灰冠战役美术

本目录的插画与首领两阶段立绘由项目使用 ImageGen 生成，作为本地静态资源随游戏分发。探索场景的社区图集和许可见[地图美术清单](../region-art/ASSETS.md)。

| 资源 | 生成与加工 | 游戏用途 |
| --- | --- | --- |
| speakers.webp | 项目使用 ImageGen 绘制八张透明像素半身像，裁切为四列两行的 256 像素方格并压缩成 WebP | 八章 NPC 对话、战后对话与前置任务提示随说话人切换立绘 |
| ferry.webp | 夜色渡口、红披风斥候、逆流军船与桅灯，横幅构图 | 渡口手记插画 |
| forge.webp | 老战士与赤红熔炉，铜铁、火花和高反差像素轮廓 | 车场手记插画 |
| mirror.webp | 雪色关隘、镜面石壁和前线人物 | 雪岭手记插画 |
| orrery.webp | 黎明星门、带盾先锋和弩手举旗，破冠龙将伏在熄炉旁 | 结局手记插画 |
| [铁冠形态](../../battle/art/ash-crown-armored.png)、[开炉形态](../../battle/art/ash-crown-enraged.png) | 同一头灰冠龙将的左向战场立绘，透明背景。分别裁切、缩放和对齐足点 | 战场根据服务器返回的首领阶段切换形态 |
| [渡口灵船](../region-art/ghost-ship.webp) | 带红帆与缆索的透明俯视船体，裁切后保留水线 | 可走到船首调查 |

战役采用经典日式 RPG 中集结队伍、向敌方首领进军的结构。八座驿站、灰冠、赤翎、选择及对白为项目创作。[《勇者斗恶龙 III》发行方介绍](https://www.square-enix-games.com/en_GB/news/dragon-quest-iii-hd-2d-remake)

白汐港、悬帆梯田、复写馆、七桥钟城及日轨天台的章节手记分别复用已有的地区全景图。玩家下达战后命令后，可以在手记里翻看决战插画。[地区图集](../region-art/ASSETS.md)

八章对白采用角色能看到、能碰到的具体事物来写。开场的敲船声，到雪岭成了赤翎认出队员的暗号。按钮写玩家马上要做的动作。语言编辑参考 [Humanizer 的写作说明](https://github.com/blader/humanizer#how-it-works)。

章节间沿用存档里的选择 ID。在渡口救出桨手，进港时就有人带你抄水路；在渡口缴了帅印，守门哨兵会直接开闸。第 2 至第 8 章各有两种这样的承接句。选择汇回主线后，以既有选择改变后续叙述的写法参考 [inkle 的《Writing with ink》](https://github.com/inkle/ink/blob/master/Documentation/WritingWithInk.md#3-tracking-a-weave)。
