# 试卷如何变成一道战斗题

从上传页选择试卷，创建 RPG 时选择界面提供的题目语言。普通课件继续走课件解析流程。已有存档保留生成时的题面；重新上传同一份试卷可使用新的解析流程。

打开含考试时长等封面题的旧远征时，战斗页提供「选择原试卷」，可直接进入新远征的文件选择页。原存档仍可继续游玩。使用这类旧资料 ID 创建新的 RPG 或配对题时，服务会提示重新上传。普通课程和已用新版解析的试卷可照常出题。

## 用一份实际失败的试卷验证

原有成品把一份英文力学期末卷首页的考试时长「3 Hours」和允许携带的 A4 纸当作知识点。使用原文件重新上传后，首题回溯到 PDF 第 3 页第 1(a) 小问。中文玩家看到完整的情境：粗糙水平面上有一只均匀实心圆柱，顶部的细线水平向右拉，圆柱纯滚动。玩家需要给出质心加速度的大小和方向。取向右为正，合力方程与转动方程给出的结果是 \(4F/(3M)\)。

## 支持边界

- 解析器先识别试卷，并将编号、共同条件、跨行小问和官方解答分开。封面、公式附页和阅卷分值留在题目范围之外。选页时宜覆盖同一题的题设和小问。
- 离线力学支持若干可核验的模型，包括基础动量与能量、向量运算、转动、波、流体和轨道力学。数值题从输入中读取条件并计算。部分符号题根据原题的物理条件改编为自足的选择题。题库没有宣称逐字转录或覆盖全卷。
- 增加外力、把实心圆柱改为空心、改变拉力方向、改变作答条件等变化会触发约束检查。能读取的数值结果和明确给出的最终公式会与本地答案比较。旧 PDF 的私有数学字形、平铺分式、嵌图和很长的推导可能让答案键核对失去可靠性。此时离线范围是条件足够明确且可独立求解的练习。
- 线上遇到本地求解器覆盖之外的题型时，优先读取官方解答。第一轮生成双语题并逐字引用答案证据，第二轮复核两种语言的正解。一道带官方解答的题至多调用两次。
- 对于题干完整、可以推理且原卷未附答案的小问，第一次请求先读原文并独立写出解法、结果和逐字条件证据，第二次据此编写双语选择题。第三、四次用各自独立的请求解中文和英文问题，面对不同顺序的选项，提交原文证据和解题步骤，逐项判断是否满足条件。两种语言都需恰好选中题库答案才会收录，解析来自对应语言的独立解题过程。来源标记为「模型独立求解与复核 (model-checked)」。多个模型调用仍可能给出同一错误，教师可复核所引题页。
- 每份上传至多向模型提交 8 个候选小问，最多 32 次文字请求，各步骤未通过就停止该小问。离线模式仍采用本地可核验的学科模型。
- 图中条件缺失、材料仅有扫描图、题面破损、解答冲突且复核尚未通过时会减少收录量。整卷缺乏可用练习时，任务会提示补充可读题页或解答。教师可检查来源页和改编题面之后决定采用的练习。

另用一份自编的无答案经济学试卷进行了线上实测。装订工可以接三本笔记本的订单，每本赚 24 枚硬币，也可以装订一本地图册赚 65 枚。题目给出两种选择的额外成本相同。OpenLux 的 GPT-5.1 从英文原题出发独立得解，中文与英文评审在各自的选项顺序中均认定笔记本订单多赚 7 枚。真实服务在开发验证中也产生过与推导不一致的选项，这些候选被丢弃。该测试使用自编试题，私人课程材料留在本机。

## 可重复的回归检查

执行 `python -m pytest -q tests/test_exam_material.py tests/test_material_bridge.py tests/test_unkeyed_exam.py`。用例覆盖封面误入题库、跨页条件、答案与题设隔离、题中数值变动、附加物理条件、官方答案冲突、扫描题页、矢量顺序、无答案题的分次盲审与调用上限。在线复核的负例使用可重复的模拟服务。
