# 课程内容排版与双语界面

连线工作室、RPG 战斗与远征使用同一套排版组件。它读取展示字段，保留判分的选项 ID、原始题干、存档和来源。公式在设备本地排版并附带 MathML，手机可以在卡片内横向查看宽公式与表格。各浏览器共享当前站点的中英偏好，学习者可在一局中途切换界面。每台设备各自保存偏好，课程内容沿用上传材料的语言。

| 输入资料 | 显示效果 |
| --- | --- |
| `$x_i^2$`、`\(x_i^2\)`、`$$...$$`、`\[...\]` | 行内或独占一行的公式，支持分式、矩阵、极限、积分、分段与常用逻辑符号 |
| `$\ce{2H2 + O2 -> 2H2O}$`、`$\pu{9.8 m/s2}$` | 化学反应式和带单位的量，由 mhchem 处理 |
| Unicode 的 `∀`、`∈`、`μ`、`²`，显式的 `<sub>2</sub>`、`<sup>+</sup>` | 文本中的原符号与上下标 |
| 用反引号标出的表达式、三反引号或三个波浪号围住的代码 | 保留缩进、运算符和代码里的美元符号 |
| 含分隔行的 Markdown 管线表 | 表头和数据单元格，保留公式内条件概率的竖线 |
| DOCX、PPTX 段落或表格里的原生 Office 公式 | 提取常用分式、根式、上下标、矩阵与带上下限的运算符，普通 Office 上下标也保留 |

**接入。** 把 `/study/study.css` 加进页面，使用 `studyMarkup(value)` 构建正文。文件名和资源属性走单独的转义路径。解析失败的 LaTeX 保留源码，未支持的 Office 公式结构会跳过该段并提示检查来源。PDF 中按几何位置排版的字符或图片可能需要视觉解析；离线提取只依据文件里可读的文字。Markdown 预览可以查看整表。离线生成器继续从带定义的资料中选题，可用题量取决于抽取到的知识点。 [渲染组件](../public/js/study.js) | [Office 读取器](../backend/office_math.py) | [KaTeX 制作与许可说明](../public/study/katex/NOTICE.md)

**组件验收。** 从本机 AIE2040 统计课程的推导题 LaTeX 中取出五段行间公式，五段均排版成功。Gamma 密度的分段、分子、分母同时在真实配对卡和首领战题面组件中出现。AIE2001 感知复习材料的感觉、受体、刺激三列表在两个组件中各保留 15 个数据单元格。两项均在 320、390 与 1280 像素宽度复核，页面宽度始终与视口一致。另从 AIE2001 作业的原生 Word 公式读取双曲贴现表达式，分母与分子经 MathML 复核。上述材料仅在本机读取，仓库的自动化测试使用自编小样。

**真实远征验收。** 在离线服务的英文主页打开“Choose course files”，将 AIE2040 的同一份推导材料整理为六条带原公式的术语定义，上传这份本机摘录。通过正常的课程提取、远征提纲、成卷和发布流程进入地图，选择普通遭遇。第一道真实题面包含可访问的 MathML，提交答案后服务端确认了回合。随后在连线工作室的资料管理中找到该远征文件，经确认删除，服务返回 204。全过程使用本机服务，摘录随测试记录一并清理。
