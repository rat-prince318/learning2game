# RPG 真实模型验收

## 验收输入

[净水站图示](rpg-fixtures/sources/water-stations.png)是团队为验收绘制的单张 PNG。图中依次列出 Screen（拦截落叶）、Sand bed（截留细砂）、Carbon bed（减少异味）、Tank（储水）。文件没有可供解析的文字层。后端实际把图片像素提交给 OpenLux 的 GPT-4.1 mini，得到四个图示知识点，均带同一原图定位及各自可观察的证据。另一份[细胞讲义](../public/examples/cell-notes.txt)用于验证文字输入。[提取的四条知识记录](rpg-fixtures/live/diagram-knowledge.json)

初期有一轮提取失败，另有两轮只保留 Tank。复查发现，模型会为同一标签各给出一条框内功能与一条下一站连线，旧去重规则会将两者视为相互冲突。现在优先保留同一图中明确标示的部件功能；同类功能彼此冲突时继续剔除。复测四项原图功能均可追溯。

## 从资料到可玩的关卡

线上工具调用与游戏回合通过 FastAPI 的真实路由和 SQLite 完成。只使用以上两份课程样例。资料理解和初期推荐使用 GPT-4.1 mini，最终关卡编排、审核与反馈使用 GPT-5.1。最终矩阵包含三个普通方案，每个方案 2 个场景、3 道题，再从图示困难关生成单题再练，共 4 个生成任务。客户端在会话中接受 NPC 任务、提交选择、推进场景、结束并读取报告。

| 输入与设置 | 任务及核查方法 |
| --- | --- |
| 净水图，初学、简单、校园主题 | 根据图中部件选择对应的功能说明，三个答案依次与筛网、砂床、碳床的原图文字吻合。 |
| 同一张图，熟悉、困难、实验室主题 | 玩家收到两条记录，从四组有序标签里选择交接顺序。核对两栏的语义、选项次序、唯一性和答后引用。 |
| 细胞讲义，初学、简单、校园主题 | 读取真正上传的讲义，按行回看细胞核、线粒体和细胞膜三个知识点，并检查干扰项来自同一份材料。 |
| 图示困难关的单薄弱点再练 | 第一题先看提示再答对，另两题直接答对。保存后从报告中请求新方案，重新确认，生成并完成单题关卡。 |

困难关中的提示与成绩是两项记录。三题均在首次作答时答对，首次正确率与完成率均为 100%；有一题使用了提示，因此报告仍列出一个薄弱点。总计 66 XP，分别来自三次答题的 6、10、10 XP 和两个任务的 40 XP。[游戏公开配置](rpg-fixtures/live/game-public.json) | [服务端报告](rpg-fixtures/live/report.json) | [单题再练](rpg-fixtures/live/practice-public.json)

首轮第一题让玩家依次识别截留细砂和拦落叶的设备，对应 Sand bed → Screen。再练仍考 Screen，但把第一条线索换成减少异味，对应 Carbon bed → Screen。验收脚本实际提交了新一局的选择并取得完成报告。开发复核逐项对照图文原件，最终这四个生成任务全部发布并完成，覆盖 10 个题次。

最终矩阵三个常规方案各约 3 秒，三次生成各约 4 至 5 秒，单题再练的生成约 5 秒。图像提取约 47 秒，文字提取约 28 秒。包括调试时期各版在内，真实数据库共记录 19 个结束的 RPG 生成任务，其中 16 个成功、3 个失败；另有 3 个早期方案任务因场景字段数不匹配，在确认前结束。最终矩阵 4/4 是选定样例上的观察。受控诊断直接调用服务，不进入上述数据库计数。

## 发现与修正

1. 初版自由生成的开场白直接写出了碳床除味，还把除味延伸为用水安全。新版让模型按证据选剧情目标、事件、线索和对照项，NPC 开场只使用内置剧情。逐题解释引用原资料。玩家作答前可见信息由单独的数据结构规定。
2. 在提示过的知识点上，第一次在线学习建议返回了错误的知识点标识，反馈任务失败，原报告仍可读。改为由后端指定每个待复习位置，模型只选复习策略。随后在同一会话重试成功。
3. 一轮真实审核把答后讲解视为答前泄题，导致两次修复后仍拒绝发布。最终审核按玩家作答前可见的字段独立解题，答案由服务端比较。困难题的答后解释同时给出两栏依据。再练优先更换实际对照知识点。
4. 为复现修复分支，另在一次受控诊断中将首次真实工具响应的事件字段改成一个未登记值，再让真实模型修复并通过程序和独立审核。该诊断与自然生成的统计分别记录。[修复工具记录](rpg-fixtures/live/controlled-repair.json)

[脱敏工具记录](rpg-fixtures/live/tool-trace.json)给出每阶段模式、状态、耗时和工具名。公开记录包含课程样例和生成结果，模型凭证及用户私有上传文件均留在运行环境。离线两门学科的 24 题另有[逐题复核](rpg-content-review.md)。这些结果测量录入、出题、出错恢复及玩法运行。学习效果还需要学生试用和教学评估。
