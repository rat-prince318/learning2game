## 检查中发现并修复的问题

1. 浏览器原生 Fetch 作为 ApiClient 对象的方法调用，导致上传请求失败：修复调用上下文，并补模块检查。
2. 重绘卡片后键盘焦点丢失：保留上一次卡片焦点，判分后转向下一张可选概念。
3. 全部匹配完成时直接读取报告：改为先调用 finish，支持后端报告任务。
4. 选择新资料/重新生成后仍残留旧引擎状态：增加清空与会话版本隔离。
5. 提取/验证终态失败时继续重试原失败任务：改为重新发起任务；未知 HTTP 结果仍保留原幂等事件。
6. 完整页面截图出现未聚焦的跳转链接：改为未聚焦时视觉隐藏、键盘聚焦时显示。
