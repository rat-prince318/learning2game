# 试卷出题与教学语言

在课程工坊或灯路远征选好中文或 English，再建立新局。教学语言随方案保存，同一局中的原题、选项、提示、解析、营地巩固和塔层练习沿用该语言。原文引证和页码保留上传资料中的写法。早期已发布关卡保留原来的内容；重新上传原件并建局即可使用新的提取与题目。

## 试卷如何变成关卡

识别器先区分作答说明、题号、小问、已知条件与解答。支持的物理模型按条件和待求量配对，生成经计算核对的中英教学题。题目可将原卷开放题改为有干扰选项的单选题。

对于其余学科，线上模式优先使用原卷的官方解答和逐字证据。原卷只有题目时，模型先独立求解，再根据原文编成双语选择题。两个独立请求分别拿到中文、英文问题和打乱的选项，各自求解并逐字引用原题条件。双方均选中目标答案才收录。来源分别标记「模型独立求解与复核 (model-checked)」，教师可对照原题复查。缺少前提或图表、残句、纯背诵和多解题会被跳过。详见[试卷出题与验证边界](exam-question-quality.md)。

- 普通战斗显示题目条件、待求量和可区分的选项。答题后可看到这道题的推导和出处。
- 营地先提供解题方向，再让玩家重新求解。高塔前段保留完整物理题，后段组合两至三道原题，每道题的选择都影响整组判定。
- 配对关卡的左卡显示完整问题，右卡显示结果。两道题得到相同数值时，右卡还给出各自推导。
- 讲义可继续用术语与定义、情境或用途生成题目。源语言与教学语言不同时，系统先准备教学译本，再生成关卡。

## 开发与离线使用

网页向出题接口提交 `question_language`，取值为 `zh` 或 `en`。远征设计、普通 RPG 设计与配对学习方案均保存此字段。API 老调用方可以省略它。旧存档继续使用其发布时的题目。

已支持的双语试题可以直接离线运行。任意讲义跨语言生成可使用项目已配置的模型服务，或先在项目目录执行以下命令安装本地翻译包。需先运行过一次 `python run.py` 建立虚拟环境。

```shell
python -m scripts.install_question_translation
```

安装器下载约 145 MB 的英语和中文模型，校验两个归档的 SHA-256，把权重放在本机 `.local/translation/`。运行时使用 CPU，课程文本留在本机。翻译保留 TeX、代码和数字；术语用词仍值得教师抽查。未安装模型又没有可用线上翻译时，系统提示如何配置。模型来源与推理引擎见 [Argos Translate](https://github.com/argosopentech/argos-translate)、[Argos 模型索引](https://github.com/argosopentech/argospm-index) 和 [CTranslate2](https://github.com/OpenNMT/CTranslate2)。

## 验收

长期回归使用自行编写的小车运动题，覆盖中英题目、相同数值答案的配对消歧、营地、塔层、公式保护、模型改变数字和离线缺包。运行 `python -m pytest -q tests/test_question_language.py`。

本地补充验收使用原版英文 PHY1001 Final 2520 PDF。通过浏览器选择中文并上传，连续三回合获取提示和作答，得到第 3 页第 1(a) 小题的圆柱质心加速度、第 3 页第 1(b) 小题的静摩擦条件和第 7 页第 3(a) 小题的重力力矩。每回合都返回中文推导、正确判分及原页码。另按中英两种语言逐题核对全部 18 条已提取小问在配对、营地和塔层的呈现。原卷、逐题回执及个人存档留在本机。
