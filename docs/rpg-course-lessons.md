# 用课程资料上第一堂远征课

在首页进入「灯路远征」，点「启程」，选择资料和出题语言。到第一个任务点和守站人交谈，就能学到与这份资料相关的方法。调查地图上有标记的地点也可以收集笔记。战斗中打开「课程笔记」可看本题相关条目，关闭后接着选答案。翻阅笔记免费，保留当前选项、回合、生命和连击。直接进战的玩家可从战前简报拿到本场需要的知识。

## 让一台电脑生成真实课程

把根目录的 `.env.example` 复制为 `.env`，设置 `EDUGAME_MODE=live` 和 `DASHSCOPE_API_KEY`。在仓库根目录运行 `python run.py`。已经运行的服务需要重启才能读到新配置。`/health` 的 `rpg_course_authoring` 为 `true` 时，启程页会显示模型课程模式。服务端使用中国内地百炼兼容端点，文本模型固定为 `deepseek-v4.1-flash-1017`。扫描页和图示由 `qwen3-vl-plus` 识读。上传资料的正文或图像会发给配置的模型服务。密钥只需留在服务端。部署可使用环境变量。[阿里云 DeepSeek 接口](https://help.aliyun.com/zh/model-studio/deepseek-api)

已发布的课程和存档保留原题库。要把旧讲义变成可收集的新笔记，回到标题，选择「启程」再上传。离线模式可以体验原有地图和战斗流程。

## 从一页材料到一场战斗

1. **找到可教的内容。** 读入 PDF、PPTX、DOCX、TXT、Markdown、PNG 或 JPEG。正文中的每个模型候选都要指向具体段落和一段能逐字找到的证据。照片试卷先转录清晰可读的文字，保存图像或页码位置。试卷有独立的题干、条件和解答解析流程。
2. **教会一个方法。** Flash 根据选定证据给初学者写短笔记，解释判断依据、使用步骤、例子或适用条件，再编写能用这个方法解决的新题。题目、笔记、选项和解析按玩家开局时选择的语言生成。课程号、讲次、目录、考试须知和待猜的上下句都要排除。
3. **分开检查“能做”和“有据”。** 一次新请求只看题干和打乱的选项，独立求解。另一次请求对照资料审核知识和笔记，检查初学者能否据此解题。有歧义、需要未展示的图或欠缺条件的题进入定点修订；整批多次失败时可逐题复核。服务提供商和模型相同，这两次检查有各自的输入。
4. **让地图、战斗与手记用同一条知识。** 笔记和练习绑定到同一个知识点，地图收集随存档保存。玩家查阅时能看到来源页、段或原题号，当前回合相关条目会标出。主线、巡逻与塔的变式可使用已审核的练习。
5. **检查公式到屏幕的最后一步。** 生成端检查数学分隔符及括号。安装 Node.js 的生成主机还会调用游戏自带的 KaTeX 和化学公式扩展预渲染，发现错误后退回修订。浏览器用同一份资源显示公式、上标、分式和化学式。原始图片用于理解材料，发布的题面始终用文字和公式提供条件。

按题保存证据定位的设计参考了 CramRAG。学科问题与支撑段落一起评估的思路参考了 EduQG。本项目沿用现有 SQLite 数据和游戏接口，两项参考用于设计与评估。[CramRAG](https://github.com/azim-git/CramRAG)　[EduQG 项目](https://github.com/hadifar/question-generation)　[论文](https://arxiv.org/abs/2210.06104)

## 本轮实测样例

使用自编的小份材料真实调用百炼，并通过 HTTP 上传、提取、规划、发布与建档。

| 资料 | 核对内容 |
| --- | --- |
| 英文 AI 课件 PPTX | 第一张保留 AIE1903、Lecture 1、Goal；第二张讲天气工具和计算器。选择中文后，战斗问玩家获取实时气温该选什么工具，笔记指向第二张。 |
| 力学试卷 PDF、拍照试题 PNG | 使用质量和速率计算平动动能，保留单位；照片上的考试时间不进入题库。 |
| 微积分 Markdown | 从端点变化量与区间长度理解平均变化率。浏览器实测走到守渡人处收集笔记，战斗中翻阅后计算并提交答案。 |
| 化学讲义 TXT | 毫升与升、浓度和溶质守恒；玩家可对照稀释公式，从已知体积和浓度推得新浓度。 |
| 电路示意图 PNG | 用文字陈述电阻接法、测量量或计算条件；题面与选项均可用文字和公式表达。 |
| 历史材料 DOCX | 根据记录者是否亲历、记录时间和所研究的问题，判断当天的航海日记能支持怎样的主张。 |
| 社会科学正文 TXT | 判断只在自行车修理店招募通勤者会遗漏哪些人。另用中文材料选择英语出题，检查英语笔记、题干和选项。 |

这批样例的十卷发布内容共 115 道题。把题干、选项、提示、解析和手记逐项送入游戏实际渲染器，844 个字段中生成了 649 处 MathML，公式解析回退和嵌图计数均为零。两卷电路资料组成的八章存档走完五场主线战斗，五条笔记均可在跨卷后查阅。桌面与手机尺寸下另测了微积分战斗，来回翻笔记期间服务端状态与回合数一致。

## 资料边界

单文件默认上限 10 MiB。一次可读取至多 80 页；上传一本较长的 PDF 时，在启程页单独选中该 PDF，再填写章节页码，例如 `122-128,131`。长篇正文在本轮模型调用额度内均匀取样，扫描件每次最多分析五幅图。按章节准备有助于提高覆盖率。

只有封面、看不清的扫描页、缺失关键条件的题目、缺少证据的开放议论，都可能没有可发布练习。可以改选正文，或补上原题的条件、解答、图注，再重新生成。模型校验仍可能漏过学科错误，课堂展示前可用课程原文核对关键结论。
