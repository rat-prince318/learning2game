## 失败记录与修正

首次线上验收三项中，两项通过，计算机再练习失败。其首轮游戏和反馈已经成功，再练习中出现语义检查引用不属于当前游戏的 ID，随后耗尽 12 次模型交互预算。原始失败保存在 [失败 manifest](../evidence/live/live_20261118T035116Z_computing_20fe99/manifest.json) 和同目录事件日志中。

检查发现语义审阅输入还包含上一轮游戏，可能把旧卡片与当前候选混在一起。修正后，语义审阅只获得当前游戏、所选知识及来源；生成和改写工具仍可读取上一轮内容。加入“语义审阅不混入上一轮卡片”的回归测试，并保留预算耗尽时最后一次验证结果。定向复测和后续完整验收均通过。

真实反馈调用中也出现过包含数值表述的摘要，程序按规则拒绝并请求重试，最终返回有效反馈。D 的统计始终作为原对象附加，没有交给模型重新计算。数值文字检查较保守，有时会拒绝非必要的数词表述；这是当前实现的已知限制。

开发内容检查还发现旧地理样例的“纬线—赤道”可能产生上下位匹配歧义。当前测试材料将赤道替换为海拔，定向真实复测通过。旧运行保留其原始输入快照。这项改进不能归为模型自动纠错的成绩。

## 完成边界与后续验收

已完成 A 的模块交付与真实 API 技术验收。三学科使用同一生成逻辑；来源随知识进入配置；用户确认、阶段权限、参数校验、有限修复、统计保真和下一轮参数均有测试或真实记录。
